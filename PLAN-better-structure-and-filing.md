# Better structure and filing

## Goal

Move the geometry code out of `assets/` into a source tree that matches what it is, split the one 1,213-line file that
has become the dumping ground for every bike part, and give the repo a written layout rule that a test enforces — so the
next part added lands somewhere obvious instead of on the end of `drivetrain.gd`.

## Architecture / proposed approach

Adopt **feature-first folders with a hard rule: code lives in `scripts/`, binaries live in `assets/`** — so the geometry
moves to `scripts/model/{engine,bike,pipe,props}/` and `assets/` goes back to holding only `.glb`, `.wav`, `.json` and
`.png`. Then split `drivetrain.gd` along the seams it already has (mesh generators, chassis, brakes, cockpit, axles,
chain) into small modules that keep the same public API, and finish by writing the layout rule down in `docs/LAYOUT.md`
and enforcing it with one guard test, so drift is caught by the suite rather than by reading the tree.

```
├── scenes/ tools/ docs/
```

**The rule, in one table** (goes into `docs/LAYOUT.md`, enforced by the guard test):

| what it is | where it goes | test goes in |
|---|---|---|
| physics, one file per model | `scripts/sim/` | `tests/unit/sim/` |
| node-building geometry | `scripts/model/<feature>/` | `tests/unit/model/<feature>/` |
| pure mesh maths (no nodes) | `scripts/model/<feature>/parts/` | same folder |
| scene-wide behaviour | `scripts/app/` | `tests/integration/` |
| screen/uGUI | `scripts/ui/` | `tests/unit/ui/` |
| any binary or data file | `assets/` | — |
| a one-off inspection script | `tools/diagnostics/` | not run by the runner |

### Task 1 — Write the guard test first (it must fail)

**Create** `tests/unit/structure/layout_test.gd`:

```gdscript
extends SceneTree

# The layout rule from docs/LAYOUT.md, checked mechanically. A refactor that leaves one stale path behind fails here,
# which is the whole point: the suite notices, not a reviewer.
# Run: godot --headless --path . -s tests/unit/structure/layout_test.gd

const REQUIRED := [
	"res://scripts/model/engine/engine_model.gd",
	"res://scripts/model/engine/crankshaft.gd",
	"res://scripts/model/engine/intake_model.gd",
	"res://scripts/model/bike/drivetrain.gd",
	"res://scripts/model/bike/car_model.gd",
	"res://scripts/model/bike/clutch.gd",
	"res://scripts/model/bike/gearbox_model.gd",
	"res://scripts/model/bike/parts/sprocket.gd",
	"res://scripts/model/bike/parts/tire_tread.gd",
	"res://scripts/model/pipe/exhaust.gd",
	"res://scripts/model/props/dyno_cell.gd",
	"res://scripts/model/props/spl_meter_rig.gd",
	"res://scripts/model/props/ground.gd",
	"res://scripts/model/props/fuel_tank_model.gd",
	"res://scripts/model/props/fuel_line.gd",
	"res://scripts/ui/motion_blur.gd",
	"res://docs/LAYOUT.md",
]

var _fails := 0


func check(ok: bool, msg: String) -> void:
	if not ok:
		_fails += 1
		print("FAIL " + msg)


func _init() -> void:
	# 1. every geometry file sits where the rule says it does
	for path in REQUIRED:
		check(FileAccess.file_exists(path) or ResourceLoader.exists(path), "missing %s" % path)

	# 2. no code is left under assets/, and none is referenced from it
	for file in _walk("res://assets"):
		if file.ends_with(".gd"):
			check(false, "code under assets/: %s" % file)

	# 3. nothing anywhere still points at the old home
	for folder in ["res://scripts", "res://tests", "res://scenes", "res://tools"]:
		for file in _walk(folder):
			if not (file.ends_with(".gd") or file.ends_with(".tscn")):
				continue
			var text := FileAccess.get_file_as_string(file)
			check(not text.contains("assets/3d/generated"), "%s still references assets/3d/generated" % file)

	# 4. no empty source folders left over from the abandoned reorganisation
	for stale in ["res://scripts/drawing", "res://scripts/ignition", "res://scripts/render"]:
		check(not DirAccess.dir_exists_absolute(ProjectSettings.globalize_path(stale)),
			"empty folder left behind: %s" % stale)

	# 5. the one file this plan splits actually got smaller
	var drivetrain := FileAccess.get_file_as_string("res://scripts/model/bike/drivetrain.gd")
	var lines := drivetrain.count("\n")
	check(lines > 0 and lines < 700, "drivetrain.gd is %d lines; the split target is under 700" % lines)

	print("RESULT: " + ("FAIL" if _fails > 0 else "PASS"))
	quit(1 if _fails > 0 else 0)


# Every file under dir, recursively.
func _walk(dir: String) -> Array[String]:
	var found: Array[String] = []
	if not DirAccess.dir_exists_absolute(ProjectSettings.globalize_path(dir)):
		return found
	for folder in DirAccess.get_directories_at(dir):
		if folder.begins_with("."):
			continue
		found.append_array(_walk(dir + "/" + folder))
	for file in DirAccess.get_files_at(dir):
		found.append(dir + "/" + file)
	return found
```

## Risks, tradeoffs, and open questions

- **`.uid` sidecars are the sharp edge.** Godot 4.7 resolves scripts by uid; a moved `.gd` whose `.uid` was left behind
  gets a new uid, and any `ext_resource` holding the old one breaks in a way that only shows when a `.tscn` loads. Move
  them in the same `git mv` pair, always.
- **`class_name` is why this is cheap.** Only 6 path references exist because the geometry is referenced by global class.
  Moving anything *out of* `scripts/model/` later must preserve its `class_name`, or those call sites become path
  references.
- **Splitting `drivetrain.gd` risks behaviour, not structure.** The mesh generators are pure and easy; the orchestration
  (`build()` order, `_wheels_ready`, `_chain_offset` state) is not. The split rule above keeps state in the host and moves
  only node-building, so `update()` stays untouched.
- **Do not rename scene nodes during the split.** Ten tests address nodes by path (`BrakeHardware/FrontCaliper`,
  `Cockpit/ThrottleGrip/ThrottleTube/Grip`, `Axles/FrontAxleNut`). Node names are part of the test contract.
- **`assets/3d/imported/*.glb` stays.** The two caliper models are genuine binaries; only the *generated* folder moves.
- **The stale worktree copy** at `.agents/worktrees/fix-neutral-to-first-blip/` still contains the old layout and will
  start failing greps. It is gitignored and belongs to an old agent session — delete the worktree rather than port it.
- **Open question:** should `scripts/platform/updates/` and `scripts/ui/launcher/` move under `scripts/app/`? They are
  entry-point code, and the rule table above has no row for them. Suggested: leave them, add the row when a third
  entry point appears (YAGNI).
- **Open question:** is a `VISION.md`/`LAYOUT.md` split worth it? The table above fits in 20 lines; a separate vision doc
  would be documentation nobody reads. Revisit only if the rule grows past one screen.
