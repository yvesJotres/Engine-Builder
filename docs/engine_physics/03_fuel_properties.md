# 3. Fuel properties

[Index](README.md) · Physics reference

| Property | Value | Confidence |
|---|---|---|
| Lower heating value, gasoline | 42.9–44 MJ/kg (NPTEL lists 43.5; IEA AMF lists 43) | [S] |
| Lower heating value, iso-octane | Not confirmed (the 44.3 MJ/kg figure was not found in any source reached) | [T] |
| Stoichiometric A/F, gasoline | 14.5–14.7 (mass) | [T] |
| Latent heat of vaporisation, gasoline | 350–440 kJ/kg (NPTEL 380; Stet Review 440) | [S] |
| Liquid density, gasoline | 720–775 kg/m³ at 15 °C (IEA AMF) | [S] |
| Liquid density, iso-octane | 690.3 kg/m³ (Sandia ECN table) | [S] |
| Enthalpy of vaporisation, iso-octane | 308.4 kJ/kg (Sandia ECN table) | [S] |
| Enthalpy of formation, isooctane (gas / liquid) | −224.1 / −259.3 MJ/kmol (corrections to Heywood, p. 77; Heywood's Table 3.2 lists n-octane values) | [S, MIT OCW] |

Charge cooling from fuel evaporation depends on the latent heat and the fuel-to-air ratio. For a rich mixture this can lower the intake charge by several kelvin [T, not quantified in any source reached].
