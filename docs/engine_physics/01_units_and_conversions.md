# 1. Units and conversions

[Index](README.md) · Physics reference

All factors below are exact or standard definitions [D].

| Quantity | Conversion |
|---|---|
| Power | 1 hp (mechanical) = 745.70 W; 1 PS (metric) = 735.50 W; 1 kW = 1.3410 hp = 1.3596 PS |
| Torque | 1 N·m = 0.73756 lbf·ft; 1 lbf·ft = 1.35582 N·m; 1 kgf·m = 9.80665 N·m |
| Pressure | 1 atm = 101.325 kPa; 1 bar = 100 kPa; 1 inH₂O (4 °C) = 249.09 Pa; 1 psi = 6.8948 kPa |
| Volume flow | 1 CFM = 4.7195 × 10⁻⁴ m³/s |
| Length | 1 thou (0.001 in) = 0.0254 mm; 1 in = 25.4 mm |
| Speed | 1 km/h = 0.27778 m/s |

Torque–power relation (four-stroke and two-stroke alike):
- P (kW) = T (N·m) × N (rpm) / 9549
- P (hp) = T (N·m) × N (rpm) / 7121
- P (PS) = T (N·m) × N (rpm) / 7024
