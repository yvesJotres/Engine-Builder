# Engine physics reference: index

Source of truth for the physics, geometry, thermodynamics and chemistry used to model piston engines. This document holds research only. It does not describe any particular simulator, engine or bike.

**Confidence tags used below**
- **[D]**: derived from definitions or arithmetic. Checkable by hand; no outside source needed.
- **[P]**: confirmed by reading a primary source itself (paper abstract, DOI record, or standard text).
- **[S]**: from a secondary source (forum, lecture note, calculator, code comment, search snippet). Use as a check; verify before relying on it.
- **[T]**: recalled from textbook knowledge and not yet re-checked against the book. Verify before use.

A value without a tag should be treated as [T].
