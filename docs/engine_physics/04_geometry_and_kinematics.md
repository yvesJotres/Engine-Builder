# 4. Geometry and kinematics

[Index](README.md) · Physics reference

**Swept volume per cylinder:** V_d = (π / 4) · B² · S, where B = bore and S = stroke [D].

**Crank radius:** r = S / 2 [D].

**Rod ratio:** R = l / r, where l = connecting-rod length (centre to centre). Typical values of 3 to 4 for small engines [S, x-engineer.org]. Other sources use rod length divided by stroke, so check the convention before comparing numbers [S].

**Instantaneous cylinder volume** (θ = crank angle from TDC):

V(θ) = V_c + (π B² / 4) · [ (l + r) − r cos θ − √(l² − r² sin² θ) ]

**Compression ratio:** r_c = (V_d + V_c) / V_c, where V_c = clearance volume [D].

**Piston displacement from crank centre:** x(θ) = r cos θ + √(l² − r² sin² θ).

**Mean piston speed:** S_p = 2 S N / 60 (m/s, N in rpm) [D].

**Angular speed:** ω = 2π N / 60 (rad/s, N in rpm) [D].

**Four-stroke cycle:** one cycle covers 4π rad (720°) of crank rotation, so there are N/2 cycles per minute [D].

**Two-stroke cycle:** one cycle covers 2π rad (360°), so there are N cycles per minute [D].
