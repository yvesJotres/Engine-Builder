## Mesh budget

The exhaust is **32 meshes / 30104 triangles**. A pipe costs detail twice over: the shell and its unshaded bore.

## Clearances

Not tabulated here, deliberately: the measurement needs the bike staged in a scene tree and a frame drawn
before global transforms resolve, and a second copy of it in this generator disagreed with the real one.
Run it directly, per preset, or read the pass/fail guarantee:

```bash
godot --headless --path . -s res://tools/diagnostics/exhaust_clearance.gd -- honda_cbr1000rrr_sp
godot --headless --path . -s tests/unit/model/pipe/exhaust_clearance_test.gd   # inline + V, must PASS
```

## What is not modelled

- No exhaust valve (EXUP), no secondary-air injection, no per-cylinder port casting.
- The canister is a chambered can with a core and one baffle plate; it has no packing, perforation pattern or
  internal passages, so its acoustic loss is the single `MUFFLER_LOSS` figure above, not a geometry.
- `yamaha_rd350` uses `scripts/exhaust/expansion_chamber.gd`, a different builder; its chamber rows are the
  cones, not a primary/collector system, so the four-stroke columns above read `—` for it.
- Car presets (`amg_*`, `m276_de30la`, `bugatti_centodieci`) are routed on a motorcycle chassis, so their
  clearance rows describe a bike frame, not a car's floorpan.
- Pipe paths here are the default routing (`ports = []`). `scripts/app/main.gd` builds them from the engine's own
  port positions, so rendered lengths differ slightly from the total-length column.
